# Contributing / Contribuer

Report reproducible behavior using the browser version, extension version, and
steps to reproduce. Remove personal information from screenshots and examples.
Never attach browser profiles, cookies, session exports, or credentials.

For changes, explain the expected behavior and verify ordinary videos, Shorts,
Playables, and Music sorting as applicable. Test with a separate browser profile.
Keep README.md and README-EN.md consistent. Build distribution packages using
`python tools/pack-release.py --output dist` and inspect their contents.

Les contributions doivent préserver les vidéos ordinaires et les réglages
documentés. Utilisez un profil de test distinct. Retirez toute information
personnelle des exemples et captures; ne joignez jamais de cookies ni de sessions.
Gardez les guides français et anglais cohérents.

Contributions are provided under the repository's MIT license.
